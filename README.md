# aiTest

一个用于 AI 测试的项目。

## 📋 项目简介

本项目旨在提供 AI 相关的测试工具和功能。

## ✨ 功能特性

- 🎨 现代化的登录页面界面
- 📱 响应式设计，支持移动端和桌面端
- ✅ 表单验证功能
- 💾 记住我功能（本地存储）
- 🔒 密码输入安全处理

## 🚀 快速开始

### 环境要求

- 现代浏览器（Chrome、Firefox、Safari、Edge 等）
- 无需安装任何依赖，直接打开即可使用

### 安装步骤

无需安装，直接使用！

### 使用方法

1. 在浏览器中打开 `index.html` 文件
2. 或者使用本地服务器运行：
   ```bash
   # 使用 Python 3
   python -m http.server 8000
   
   # 使用 Node.js (需要安装 http-server)
   npx http-server
   ```
3. 在浏览器中访问 `http://localhost:8000`

### 演示账号

- 用户名: `admin`
- 密码: `admin123`

> 注意：当前为演示版本，登录验证为前端模拟。实际项目中应连接后端 API。
